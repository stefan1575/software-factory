# Software Factory

Shows where a software project stands, and later runs its work.

**Experimental.** It changes without notice and is not ready for anyone else to use.

## The rule it is built on

Software Factory owns nothing it can read elsewhere.

| What | Where it lives |
|---|---|
| The work: efforts and tickets | GitHub issues |
| The code and its progress | GitHub pull requests |
| Its own choices | Software Factory |

It keeps no copy of a project. Every time it opens one, it reads what is there.

## Status

The reading core is built, with no screen: it reads one GitHub repository and prints its efforts,
the tickets under each, and how far along each is.

A desktop window shows that picture, on made-up data for now.
